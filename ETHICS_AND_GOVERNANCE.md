# Ethics and Governance

This project is an analytical portfolio-risk case study. It is not a production lending decision system.

The full framework covers fairness, privacy, transparency, explainability, data minimisation, purpose limitation, model risk, responsible lending, human oversight, monitoring, bias, proxy discrimination, reproducibility and limitations.
